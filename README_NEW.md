# Triozy

A Flutter app for housing and flatmate discovery with chat, listings, and onboarding flows.

## Features
- Browse housing and marketplace listings
- Chat with listing owners or flatmates
- Location search and filters
- Onboarding and profile completion

## Tech Stack
- Flutter (Dart)
- Firebase Auth and Firestore
- Provider for state management

## Getting Started
1) Install Flutter and Firebase CLI.
2) Configure Firebase with FlutterFire.
3) Run the app.

## Configuration
- Firebase config: run `flutterfire configure` to generate `lib/firebase_options.dart`.
- Android signing: set up `android/key.properties` for release builds.

## Run
- `flutter pub get`
- `flutter run`

## Build
- `flutter build apk`
- `flutter build ios`
- `flutter build web`

## Project Structure
- `lib/` app code (screens, services, providers, widgets, theme)
- `android/` Android native project
- `ios/` iOS native project
- `web/` Web entrypoint and assets
